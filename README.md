Variables
What is a variable?

A variable is a named place used to store information or a value that can change.

For example, in JavaScript:

let name = "Shilla";
let age = 20;

Here:

name is a variable storing "Shilla"
age is a variable storing 20
What about HTML?

HTML is used mainly to structure and display content on a webpage. It uses things such as:

Elements – <p>, <h1>, <div>, <img>
Attributes – id, class, src, href, style
Tags – <html>, <body>, <head>

For example:

<p id="studentName">Shilla</p>

Here, id="studentName" is not a variable. It is an HTML attribute that gives the paragraph a name/identifier.

Simple difference
HTML	JavaScript
Structures a webpage	Adds programming/logic
Uses elements and attributes	Uses variables
<p>Hello</p>	let message = "Hello";
